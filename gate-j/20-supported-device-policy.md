# Supported Device Policy

Fully supported:

- None certified by Gate J because mobile and real-camera validation were blocked.

Supported with reduced mode:

- None certified by Gate J.

Fallback supported:

- Desktop Chrome and Edge runtime fallback messaging passed with limitations in headless probes.

Unsupported:

- Browsers lacking secure context, camera APIs, JavaScript, canvas, WASM, or media playback.

Release wording should be: full tracked scanning is supported only on validated modern browsers. Weaker compatible devices use reduced modes. Unsupported devices receive direct-content fallback where configured.
