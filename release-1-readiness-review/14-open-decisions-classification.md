# Open Decisions Classification

## Must Decide Before Implementation

Workspace billing ownership, Project-to-Experience compatibility, QR compatibility, scanner contract versioning, public/private Experiences, fallback billing, overage/grace behavior, migration rollback, role enforcement model, entitlement schema, asset/storage identity, recognition artifact versioning, and deletion/archive semantics.

## Must Decide Before AWS Staging

Object storage, queue technology, worker deployment, CDN, domains, email provider, monitoring, secrets, backups, malware scanning provider.

## Can Decide During Implementation

Exact UI role presets, default fallback template, trigger QR UI/API exposure, analytics geography granularity.

## Can Defer After Release 1

SSO, enterprise invoicing, purchase orders, developer API billing, future 3D, future WebXR, marketplace.
