# Risk Register

Highest risks:

- Existing QR or scanner URL breakage.
- Scanner contract response-field breakage.
- Migration data loss or partial migration.
- User/workspace billing mismatch.
- Admin-owned versus user-owned project confusion.
- `.npz` feature incompatibility.
- Weak mobile scanner or endless loading.
- Incorrect billing of recognition attempts.
- Tenant isolation failure.
- Security regressions in auth, upload, and public media.

Full register is in `risk-register.csv`.
