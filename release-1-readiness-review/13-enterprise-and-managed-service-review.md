# Enterprise And Managed Service Review

## Foundation Required Now

Workspace, roles, audit log, entitlement keys, custom limits, managed-service ownership, support diagnostics, and future custom-domain gates.

## Safe To Defer

SSO, regional hosting, dedicated deployment, purchase orders, custom integrations, full API access, bulk order automation, advanced white labeling.

## Scope Risk

Enterprise, education, agency, and managed-service foundations are useful only if they stay configuration-first. They should not expand Release 1 scanner bundle, dashboard payload, or migration scope.

Canonical principle: Configure first -> extend second -> customize third -> fork only as last resort.

Enterprise foundation score: **70/100**.
