# Gate B Exit Criteria

Gate B passes when:

- Gate A is committed.
- Gate B branch is active.
- test mode is enforced.
- DB/storage paths are guarded.
- SMTP/Razorpay/HTTP external calls are blocked.
- password reset coverage is improved.
- admin coverage is improved.
- upload edge coverage is improved.
- strict xfails are justified.
- three consecutive repeatability runs succeed.
- no real DB/media is touched.
- no Release 1 models/features are implemented.
