# Release 1 Scope

## In Scope

- Public site, registration, email OTP, login, logout, password reset.
- Workspace creation, members, roles, billing ownership, and plan state.
- Experience creation with one or more image/video triggers.
- Upload validation, media optimization, marker-quality scoring, feature generation.
- Processing states, retry paths, diagnostics, preview, testing, approval, publishing.
- Permanent Experience QR and public link.
- Optional trigger-specific QR/link.
- Browser scanner with capability detection, guided scanning, video overlay, and fallback.
- Server-assisted recognition, geometric verification, optical-flow tracking, periodic re-anchoring.
- Analytics, usage metering, admin/support visibility.
- Enterprise, agency, education, managed-service foundations.
- Security, privacy, performance budgets, cloud-ready storage/queue abstractions.

## Out Of Scope

- 3D models, WebXR, VR, spatial anchors, plane tracking, native mobile apps.
- Physical object, place, face, body, pose, or location recognition.
- AI-generated scenes, marketplace, public SDK, multiplayer.
- Source code changes, database migrations, dependency installation, AWS setup, or optimization work in this specification task.

## Release Rule

Anything that does not improve image-triggered video creation, publishing, viewing, billing, support, or reliability stays out of Release 1.
